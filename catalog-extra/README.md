# Hand-added catalog items

Put `<category-id>.json` files here (`{"items": [...]}`) to add hardware the open
datasets don't cover yet (brand-new launches, microphones, controllers, ...).
Each item needs `id`, `name`, `maker` and ideally `year`/`date`; any other keys
are shown as specifications. The catalog workflow merges these on the next run.
Category ids are listed in `catalog/index.json`.
